\begin{abstract}
This project explores whether the frequency domain is still a useful place to look for AI-generated image artifacts now that diffusion models have largely replaced GANs. We build \textbf{Eigenfraud}, a simple detector that never looks at pixel values: every image is converted to its 2D log-power spectrum via FFT, and we train two small CNNs on complementary views of that representation: a 1D CNN on the azimuthally averaged radial profile (isotropic structure only, $\sim$180k parameters) and a 2D CNN on the full centered spectrum (isotropic and anisotropic structure, $\sim$4M parameters). Neither model touches pixels, and neither uses pretrained weights or data augmentation. The main question we want to answer is whether diffusion fingerprints are isotropic (making the simpler 1D model sufficient) or whether the full 2D structure carries extra signal.

On CIFAKE~\cite{cifake} (Stable Diffusion v1.4 vs CIFAR-10), the 2D model reaches a validation AUC of 0.953 and the 1D model 0.940, which is a small gap on this single-generator benchmark. On Defactify~\cite{defactify} (a multi-generator mixture), the gap widens to 0.905 vs 0.844, which is consistent with the idea that directional artifacts matter more when the generator pool is diverse. We also trained on a four-generator subset of GenImage~\cite{genimage} (ADM, BigGAN, VQDM, GLIDE), where the 2D model reaches a test AUC of 0.999 and the 1D model a validation AUC of 0.938 on in-distribution evaluation, though the near-perfect GenImage result should be read with caution given documented JPEG-quality biases in that dataset~\cite{grommelt2024}. The results, while preliminary, do suggest that the frequency-only approach survives the transition from GANs to diffusion models, and that the full 2D representation is more useful than the radial average as generator diversity grows.
\end{abstract}
